Rules for Robots lets one person direct agents through a whole project by approving decisions, never commands. The person approves what the work should be (a brief, a design, the documentation users will read) and whether the result is right. Agents do everything in between without asking. What must never happen is made impossible, not asked about; what must be true is checked by CI; who approved what is recorded in GitHub. It works for a weekend script and for a product with many features, and the same approach applies to software, to media, and to research.

**Start at [rules-for-robots](https://github.com/RulesForRobots/rules-for-robots)**: the charter, which plugins to install, and the `rfr` plugin marketplace for Claude Code.
